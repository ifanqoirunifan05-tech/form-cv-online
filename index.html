PEMBUAT CV

Isi formulir, periksa pratinjau, lalu unduh CV Word atau simpan sebagai PDF.

1. Foto Profil

Gunakan foto JPG atau PNG. Maksimal 5 MB.

2. Data Diri

3. Pendidikan

4. Pengalaman Kerja

5. Keahlian

6. Tentang Saya

7. Dokumen Pendukung

Pilih gambar ijazah, sertifikat, atau dokumen pendukung. Gambar akan disisipkan ke pratinjau, Word, dan hasil cetak PDF. Untuk PDF/dokumen asli, versi ini mencantumkan nama file saja; isi PDF asli belum digabungkan.

Belum ada dokumen dipilih.

Pratinjau CV

Isi formulir lalu tekan BUAT / PERBARUI CV.

Cara Pakai

1. Isi data diri, pendidikan, pengalaman, dan keahlian.

2. Upload foto profil dan gambar dokumen pendukung jika ada.

3. Tekan BUAT / PERBARUI CV dan periksa pratinjau.

4. Tekan DOWNLOAD WORD (.DOC) untuk menyimpan Word.

5. Tekan SIMPAN PDF, lalu pilih Simpan sebagai PDF pada menu cetak browser.
